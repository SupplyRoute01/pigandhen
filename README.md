# Pig & Hen

암스테르담 핸드메이드 주얼리 브랜드 **피그앤헨(Pig & Hen)**의 한국어 정적 웹사이트입니다.

## 실행

빌드 도구나 설치가 필요하지 않습니다. `index.html`을 브라우저에서 직접 열거나 간단한 정적 서버를 사용하세요.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 파일

- `index.html`: 전체 콘텐츠와 5개 섹션
- `styles.css`: 반응형 레이아웃과 디자인 토큰
- `script.js`: 모바일 메뉴, 섹션 표시, 제품 필터
- `DESIGN.md`: 브랜드 디자인 시스템

## 브랜드 자산

헤더·푸터 로고와 제품·캠페인 이미지는 피그앤헨 본사 사이트의 공식 CDN 자산을 사용합니다. 따라서 온라인 상태에서 모든 이미지가 표시됩니다.

## 상품 정보 출처

상품 143개의 이름, 가격, 이미지, 구매 링크는 `2026-08-29`에 제공된 네이버 브랜드스토어 자료 6개를 합친 결과입니다. 다른 브랜드 상품을 제외하고 URL 기준 중복을 제거했습니다.
